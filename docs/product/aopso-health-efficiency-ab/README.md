# AquaOptima Pump Station Optimizer Lite — Health & Efficiency Advisory (A+B)

Unified two-pillar **offline, advisory-only** product plan for the single legacy Yilan pump station.
This product is a **pivot** away from short-horizon telemetry forecasting, which failed twice
independently against the LOCKED March 2026 benchmark:

| Sprint | Target | Horizon | Beat persistence on |
|--------|--------|---------|---------------------|
| 25 | absolute | 1 step (60s) | **0 / 6** continuous axes |
| 26 | residual-over-persistence | 15 min | **0 / 8** axes (defects fixed → failure confirmed real) |

Persistence (last-value) is genuinely hard to beat on this highly autocorrelated 60s single-site
telemetry. So we stop competing with it on forecasting and build the two objectives where a learned
model legitimately adds value:

- **Pillar A — Anomaly / Health Detection.** Learn the normal operating envelope; flag drift, pump
  degradation, sensor faults. Baselines to beat: persistence **and** SPC (EWMA/3-sigma). Evaluated
  offline via injected-fault harness + locked March 2026 holdout.
- **Pillar B — Efficiency Advisory / dPL.** Learn the efficient setpoint envelope per operating point
  (kWh/m³). Compare advisory operating points against MVPv1 control logs + 2025 auto-mode **without
  ever actuating**. Report offline opportunity, not guaranteed savings.
