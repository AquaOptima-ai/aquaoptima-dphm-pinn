# Qualified PAC-like Edge Product

## Purpose

The long-term edge product should behave like a trustworthy industrial control component: deterministic, observable, fail-safe, auditable, and aligned with PAC/OT engineering expectations.

## Required capabilities

- Deterministic control loop with deadlines.
- Watchdog and heartbeat monitoring.
- Fail-safe state machine.
- Local manual override and maintenance lockout.
- Secure protocol adapters.
- Signed deployment bundles.
- Runtime health API/dashboard.
- Hardware-in-the-loop and fault-injection testing.
- Commissioning and site acceptance procedures.

## Qualification note

This roadmap can produce a PAC-compatible or PAC-like candidate, but formal qualification/certification depends on hardware, site validation, OT/security review, and applicable regulatory requirements.
